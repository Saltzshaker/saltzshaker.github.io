# Archive

Old pages taken offline in November 2026. Jekyll skips folders that start with
an underscore, so nothing in here is published.

- `archive-old-site/` - the full 2016-2022 site (posts, pages, layouts)
- `pages/` - old About and Writing pages
- `_posts/` - old project posts no longer linked from the site
- `old-site.html` - the earlier homepage snapshot

To bring a page back, move its file back to the repo root, `pages/` or `_posts/`.
